```
1. 정기적으로 세안하고 건조
2. 알레르기 유발 요인 확인 및 피하는 것
3. 균형 잡힌 영양 공급

```

```
3. **감염 (Infections)**: 비슷한 원인으로도, 감염성 질환(예: 홍역, 파보바이러스 감염)이 발생할 수 있습니다.

4. **기생충 감염**: 애벌레나 기생충(예: 눈 벌레) 감염이 있을 경우 노란 눈곱과 같은 증상이 나타날 수 있습니다.

5. **기타 원인**: 피부 질환, 약물 복용, 기타 환경적 요인도 영향을 미칠 수 있습니다.
```
